# Нұр

Мобильное приложение для мусульман (Android и iOS) на Expo / React Native. Интерфейс на казахском, с переключателем на русский.

## Что внутри

- **Намаз:** время пяти намазов офлайн (библиотека `adhan`), GPS или выбор города, дата по хиджре, уведомления азана.
- **Кибла:** компас с направлением на Каабу и расстоянием до Мекки.
- **Коран:** 114 сур. Арабский текст (Усмани), транскрипция кириллицей или латиницей, перевод Халифы Алтая (каз.) или Эльмира Кулиева (рус.), аудио Мишари аль-Афаси по аятам.
- **Хадисы:** «Сахих аль-Бухари» и «Сахих Муслим» на русском с арабским оригиналом. Загружаются по разделам и кэшируются на устройстве.
- **Зикры:** тасбих-счётчик, утренние, вечерние и азкары после намаза.

Фон экранов меняется по времени текущего намаза: рассвет, день, предзакатное время, закат, ночь.

## Запуск

```bash
npm install
npx expo start
```

Отсканируйте QR-код приложением Expo Go (Android) или камерой (iPhone).

## Сборка для магазинов

```bash
npx eas-cli@latest login
npx eas-cli@latest build --platform all --profile production
npx eas-cli@latest submit --platform all
```

Нужны аккаунты Google Play Console и Apple Developer.

## Данные

- Коран: [fawazahmed0/quran-api](https://github.com/fawazahmed0/quran-api). Тексты собираются в `assets/quran` скриптом `scripts/build-quran.py`. Кириллическая транскрипция генерируется из латинской автоматически и приблизительна.
- Хадисы: [fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api). Оглавление строит `scripts/build-hadith.py`, тексты загружаются во время работы приложения.
- Аудио: [everyayah.com](https://everyayah.com).
